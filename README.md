# 基于 Pearson 相关系数与 LLM 语义增强的电影推荐系统

## 📌 项目概述

本项目是一个基于协同过滤（Collaborative Filtering）算法的轻量级电影推荐系统。项目核心利用 **Pearson 相关系数** 解决用户评分尺度不一的偏差问题，并创新性地接入 **DeepSeek 大语言模型 (LLM)**，为生成的推荐列表提供具有“可解释性”的语义推荐理由。

## 🚀 技术亮点

* **数学建模**：采用 Pearson 相关系数代替传统余弦相似度，通过中心化（Mean-Centering）有效消除“宽松型”与“严苛型”用户之间的评分基准偏差。
* **统计优化**：引入显著性加权（Significance Weighting）机制，针对共同评分数较少的用户对进行相关性惩罚，提升了小样本下的预测鲁棒性。
* **LLM 落地应用**：利用 **DeepSeek-V3 API** 实现了推荐理由的自动化生成，将冷冰冰的相似度数值转化为用户可理解的语义逻辑。
* **工程实践**：实现了从数据预处理、相似度矩阵计算、到 API 异步调用（基于 `openai` 库）的完整流水线。

## 🛠️ 核心模块说明

### 1. 统计学内核：Pearson Correlation

相比于普通余弦相似度，Pearson 系数关注的是向量的**线性相关性**。


$$r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \sum (y_i - \bar{y})^2}}$$


通过减去均值 $\bar{x}$，模型能够识别出：用户 A 的 5 分和用户 B 的 3 分可能代表同等程度的“喜爱”，从而捕捉到更真实的兴趣共鸣。

### 2. 推荐解释器：LLM Reasoning

通过 Prompt Engineering，模型不仅给出“推什么”，还解释“为什么”。

* **输入**：用户观影历史 + 算法推荐影片。
* **输出**：基于导演风格、时空背景或情感内核的深度推荐语。

> *示例：针对喜欢《盗梦空间》的用户推荐《星际穿越》，AI 会自动识别出“诺兰时空执念”这一高阶语义联系。*

## 📈 总结与复盘

1. **偏差修正**：通过 Pearson 公式实验，验证了在主观打分场景下，去中心化操作能显著降低噪声。
2. **工程 Debug**：解决了 API 调用过程中的网络连接（Connection Error）及环境变量配置问题。
3. **未来改进**：
* 引入 **Embedding-based Retrieval**：利用 LLM 将电影简介转化为高维向量，解决冷启动问题。
* 性能优化：在大规模数据下引入 K-Means 聚类以降低相似度矩阵的计算开销。
* 引入惩罚项，降低热门电影的马太效应，注重发掘小众电影的精准推荐。
利用信息论的思想，电影 $j$ 的热门度惩罚权重 $w_j$ 可以定义为：


$$w_j = \log \left( \frac{N}{n_j} \right)$$


其中 $N$ 是总用户数，$n_j$ 是评价过电影 $j$ 的用户数。
