# Movie-Recommendation-system
原始索引不起决定性作用，主要是位置索引定位返回电影名称
首先读取数据，根据电影种类创建标签并创建矩阵。
其次通过计算cosine_similarity得出test_movie与其他movies的相似度数组。对其中每个元素创建位置索引（注意不是原始索引/行号），enumerate把原始索引映射成(0，1，2，...)，对相似度进行降序排序，切片。
输出result时排除test_movie。针对位置编号返回电影名称
最后输出相似的电影

缺点：
1.无论分数高低，都返回相似的电影，但不满足观众的需求。
2.不能预测其他观众想看的类型的电影，比如看惯了动作片想看文艺片。
